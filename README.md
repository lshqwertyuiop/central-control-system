# central-control-system

中控系统前端原型，覆盖库存看板、入库任务、加工任务等业务页面。

## 使用方式

使用浏览器打开 `中控系统.html` 即可查看系统原型。

在线查看最新版: https://lshqwertyuiop.github.io/central-control-system/

## 新建预排产

从「排产列表 → 新建预排产」进入三步流程：

1. 从计划列表选择切割包或单根型材，创建排产工单。
2. 自动方式沿用现有排产算法与通路配置；手动方式支持多选型材，指定出库口、喷码、切割机及单根加工顺序。
3. 核对甘特图、工单、单根时间线及换盘统计；支持拖拽排序和跨机移动，最后填写生产日期、排产序号与班次并保存。

手动指定允许任意出库口、喷码和切割机组合；跨机拖拽保留原出库口和喷码指定。保存后返回预排产列表，支持展开追溯单根分配及顺序。预排产数据保存在当前浏览器的 localStorage 中，当前前端原型不包含服务端同步。

单根分配、三步流程、本地保存逻辑及对应样式已直接内置于 `中控系统.html`，无需额外排产 JS/CSS 文件。`index.html` 同步保持一致。
